🏛️ Architecture Philosophy

Decoupled 7-Layer Strict Hierarchy: In Indian PSUs (refineries, petrochemical complexes, gas pipelines), safety and regulatory compliance demand zero probabilistic guesswork. If a model hallucinates, plant equipment can rupture. This architecture isolates AI synthesis into Layer 4, forcing all engineering decisions through deterministic math in Layer 3 and immutable schemas in Layer 1.

🔄 Data Dependency Rule

Strict Downward-Only Coupling: High layers depend strictly on lower layers. Layer 7 (UI/CLI) imports Layer 5 (Orchestration). Layer 5 imports Layer 4 (Models) and Layer 3 (Physics Tools). Layer 3 NEVER imports Layer 5. This prevents circular dependencies and ensures every subsystem can be tested in isolation.

📑 Layer-by-Layer Breakdown

  • Layer 0 (Runtime): Localhost port 11434 daemon, NTFS junction to project root, zero Windows registry pollution.
  • Layer 1 (Contracts): Typed Pydantic models (InspectionInput, CalculationOutput) preventing drift.
  • Layer 2 (Perception): Regex extractor + VLM adapter converting noisy field logs into structured data.
  • Layer 3 (Deterministic): ASME UG-27 math, API 510 remaining life, 15s subprocess sandbox.
  • Layer 4 (Model Pool): Specialized SLMs: Qwen (coding), DeepSeek-R1 (reasoning), Llama-3.2 (summary), Moondream (vision).
  • Layer 5 (Orchestration): Golden Path pipeline & LangGraph state machine with validation retry loops.
  • Layer 6 (Emission): Tamper-evident Word (.docx) & PDF (.pdf) compilers with SHA-256 integrity hashing.
  • Layer 7 (Gateway): Master CLI (main.py) & Streamlit 6-tab workbench (frontend/app.py).

🤝 Teammate Collaboration & Refinement

  • Adding New Physics Formulas: Add strictly in tools/asme_calculator.py (Layer 3) and update schemas/mvp_schema.py (Layer 1).
  • Upgrading a Model: Change mapping in config/settings.py (Layer 0). No math or document generation code needs to change.
  • CLI Testing: Test all 7 layers at once by running python main.py status.

🧭 Lifecycle of an Industrial Audit Request

1. Entry: Operator enters request in Streamlit (frontend/app.py) or terminal (main.py).
2. Orchestration: agent_orchestrator/orchestrator_mvp.py triggers the 4-step Golden Path.
3. Parsing: ingestion/extract_inspection_data.py pulls tags and wall thicknesses from field notes.
4. Physics Verification: tools/asme_calculator.py calculates $t_{\\text{min}}$ and remaining safe service life.
5. Regulatory Synthesis: models/reasoning_models/reasoning.py invokes DeepSeek-R1 for CVC DOP 4.2 compliance.
6. Emission: output_generation/docx_generator.py & pdf_generator.py write formatted files to data/output/ with SHA-256 hashes.
7. Delivery: Returns FinalNFAPayload with 1-click download buttons.

📁 Directory Ownership & Responsibilities

  • agent_orchestrator/: Central state machine, sequential pipeline, and self-correction loops.
  • config/: Centralized paths, model registries, and disk space preflights.
  • frontend/: 6-tab Streamlit dashboard with real-time progress indicators.
  • ingestion/: OCR text cleaning, regex token extraction, and defect parsing.
  • models/: Small language model handlers, streaming downloaders, and prompt templates.
  • output_generation/: Native Word & ReportLab PDF generators with corporate IOCL styling.
  • schemas/: Shared Pydantic data contracts ensuring zero data drift between teammates.
  • tools/: Deterministic ASME calculation engine, subprocess Python sandbox, and local RAG.

📐 ASME Section VIII Div 1 UG-27 Formula

The deterministic physics engine calculates minimum required shell thickness using:

t_req = (P * R) / (S * E - 0.6 * P) + CA

For vessel 11-V-102: P = 14.5 MPa, R = 1200 mm, S = 138 MPa, E = 1.0, CA = 4.0 mm.
Calculated: t_req = 138.57 mm.
Actual Measured: t_actual = 138.20 mm.
Delta: Delta = 138.20 - 138.57 = -0.37 mm (STATUTORY CODE VIOLATION).

⏱️ API 510 Remaining Safe Service Life

Calculates remaining operating time before mandatory shutdown:

Life (years) = (t_actual - t_req) / Corrosion_Rate

With an observed corrosion rate of 0.75 mm/year, Remaining Life = -0.49 years (Expired). Derated MAWP is computed to establish safe temporary operating pressure until the turnaround.

⚖️ CVC Guidelines & DOP Clause 4.2

Government of India Central Vigilance Commission (CVC) Circular No. 02/02/2004 forbids single-source procurement EXCEPT in certified emergency operational crises. Under Delegation of Powers (DOP) Clause 4.2, the breach of ASME safety limits provides the formal legal basis for emergency single-source engagement of OEM weld overlay contractors.

⚡ Heuristic Intent Classification

models/router/model_router.py classifies prompts in under 5ms without burning LLM inference tokens:

  • Coding: Keywords like python, def, script, modbus, scada, sql ➔ qwen2.5-coder:1.5b
  • Reasoning: Keywords like asme, api 510, breach, cvc, dop, mawp ➔ deepseek-r1:1.5b
  • Vision: Images attached or keywords like p&id, diagram, blueprint ➔ moondream
  • Summary: Default text or keywords like summarize, bullet points ➔ llama3.2:3b

🧪 Air-Gapped Sandbox Execution Architecture

When an LLM produces Python code, executing it directly in the parent process is dangerous. tools/sandbox.py executes the code in an isolated subprocess with:

  • Strict 15-second timeout to prevent infinite loops.
  • Isolated memory space preventing parent crash on segfault.
  • Capture of both standard output (stdout) and error tracebacks (stderr).
  • Automatic temporary file deletion on completion.

📄 Automatic Deliverable Detection

When user prompts include intent phrases like "need docx", "need pdf", "download approval note", "give me docx", the router automatically compiles the official Word (.docx) and PDF (.pdf) documents and presents immediate 1-click download buttons with SHA-256 integrity hashes.

    Emitter -->|Deliverables Compiled & Signed| END

    %% Self-Correction Feedback Loops (Attempts < 2)
    CondVal -.->|is_valid == False & route == 'coding'| AgentCoding
    CondVal -.->|is_valid == False & route == 'reasoning'| AgentReasoning
    CondVal -.->|is_valid == False & route == 'summary'| AgentSummary
    CondVal -.->|is_valid == False & route == 'multimodal'| AgentVision
    CondVal -.->|is_valid == False & route == 'pipeline'| AgentVision

🤖 Multi-Agent State Machine Architecture

Built with langgraph and typed via agent_orchestrator/state.py. The shared AgentState carries user prompt, input modalities, attached files, route assignment, model responses, retry attempt count, and validation flags.

🔄 Two Core Execution Modes

1. Direct Delegation Mode: Router evaluates prompt ➔ Dispatches to single specialized worker node (Coding, Reasoning, Summary, or Multimodal) ➔ Passes to Validator ➔ Terminates at END.
2. Sequential Pipeline Mode (Full Audit): When prompt asks for 'full audit' or 'pipeline', executes the sequential chain: Multimodal ➔ Coding ➔ Reasoning ➔ Summary ➔ Validator ➔ END.

🛡️ Validator & Self-Correction Retry Loops

The validator_node inspects model responses. If the output fails validation (syntax errors or empty response) and attempts are under 2, it loops back to the assigned worker node for retry. If attempts reach 2 or validation passes, it cleanly exits to END.

🔗 Windows NTFS Junction (mklink /J) Mechanics

By default on Windows, Ollama stores model weights in C:\Users\<User>\.ollama\models. To keep the project self-contained without downloading models twice, we created an NTFS Directory Junction: model_pool\ollama ➔ C:\Users\DELL\.ollama\models. Both paths reference the exact same physical disk sectors with zero duplicated storage.

🔒 Zero Host Pollution & Portability

All temporary data, uploaded field blueprints, and compiled Office deliverables are strictly confined within the project directory:
- Model Weights: model_pool/
- Generated Reports: data/output/
- User Uploads: data/uploads/
Zero temporary files are scattered across Windows system directories.

🧹 1-Click Zero-Trace Teardown

When the system needs to be cleaned or uninstalled:
- scripts\clean_models.bat: Safely deletes model weight blobs, freeing 6-10 GB of disk space.
- scripts\uninstall_all.bat: Removes all virtual environments and models leaving zero footprint.
